# TruckDiag downloads

Diagnostic software for trucks and heavy machinery (SAE J1939) and cars (OBD-II).

## Download

Go to **[Releases](../../releases/latest)** and download:

- **Windows:** `TruckDiag-Setup-<version>.exe` — double-click to install.
- **Mac (Apple Silicon, M1 and newer):** `TruckDiag-<version>.dmg` — open it and drag TruckDiag into Applications.

Installed copies update themselves: when a new version is out, TruckDiag asks "Update now?" when it opens.

Truck adapters (CAT Comm Adapter 3 and other RP1210 adapters) work on Windows only. On a Mac, TruckDiag reads cars
through a USB or Wi-Fi ELM327 adapter.
